# 本地会议记录 AI 工具 PRD（精简可开发版）

## 1. 产品定位

建设一个本地私有化会议记录 AI 工具，支持 PC/手机录音、音频上传、本地语音识别、自动纠错、模板化会议内容提取、会议纪要导出，并为后续客户/项目知识沉淀打基础。

核心链路：

```text
录音/上传 → 音频预处理 → VAD切分 → 本地ASR识别 → 转写编辑 → 术语纠错 → 模板提取 → 会议纪要/原始记录导出
```

## 2. 目标用户

- 公司内部销售/售前工程师
- 项目经理
- 老板/管理者
- 后续可扩展给客户内部使用

## 3. V1核心目标

V1 不追求复杂实时字幕和手机 App，优先解决：

1. 会议音频能上传或录制
2. 能在本地服务器完成语音识别，不上传外部平台
3. 能查看、编辑、纠错转写文本
4. 能按模板生成会议纪要
5. 能导出 Word / Markdown
6. 能绑定客户和项目，便于后续沉淀

## 4. V1功能范围

### 4.1 会议管理

- 新建会议
- 编辑会议标题、会议类型、客户、项目、参会人、会议时间
- 查看会议列表
- 查看会议详情
- 删除会议

### 4.2 音频采集

V1支持：

- 上传音频文件：mp3、wav、m4a、aac
- PC浏览器录音
- 手机浏览器录音

暂不做：

- 原生手机 App
- 微信/腾讯会议自动同步
- 实时在线多人会议接入

### 4.3 音频预处理

使用 ffmpeg 对音频进行标准化：

- 转 wav
- 单声道
- 16kHz采样率
- 音量归一化
- 可选基础降噪

### 4.4 VAD切分

使用 VAD 检测有效人声片段：

- 去除静音
- 长音频切分为短片段
- 生成片段起止时间
- 便于ASR并行识别

### 4.5 本地语音识别

推荐默认引擎：

- FunASR / SenseVoiceSmall

预留备用引擎：

- faster-whisper / Whisper large-v3-turbo

部署原则：

- 开发阶段：可安装在开发机用于调试
- 正式使用：部署在服务器或独立ASR容器中
- 前端不直接调用ASR，统一由后端调度

### 4.6 转写结果管理

- 显示完整转写文本
- 按片段显示时间戳
- 支持编辑文本
- 支持重新识别单个片段
- 支持文本与音频片段对应
- 后续可扩展说话人区分

### 4.7 术语纠错

维护术语库：

- IT行业术语
- 厂商品牌
- 产品型号
- 客户名称
- 人名
- 自定义替换规则

例：

```text
防火强 → 防火墙
华三 → H3C
深信服超容和 → 深信服超融合
```

### 4.8 模板化会议纪要

支持模板管理：

- 通用会议纪要模板
- 售前客户交流模板
- 项目推进会议模板
- 技术方案讨论模板
- 招投标沟通模板

模板要求：

- 可新增
- 可编辑
- 可禁用
- 可版本化预留

### 4.9 会议纪要生成

基于纠错后的转写文本和模板 Prompt，生成：

- 会议摘要
- 结构化纪要
- 行动项
- 待确认事项
- 风险点
- 下一步建议

### 4.10 导出

V1支持：

- 原始转写记录 Markdown
- 原始转写记录 Word
- 会议纪要 Markdown
- 会议纪要 Word

后续支持：

- PDF
- JSON结构化导出
- 推送到客户知识库/CRM

## 5. V1不做范围

- 实时字幕作为核心能力
- 语音克隆/TTS
- 多模型投票融合
- 复杂审批流
- 多租户SaaS
- 声纹绑定真实姓名
- 自动同步微信/腾讯会议

## 6. 关键体验要求

1. 转写结果必须可编辑
2. 会议纪要模板必须可编辑
3. 音频和文本最好能按时间戳对应
4. 失败任务可重试
5. 长音频必须异步处理，不能阻塞页面
6. 音频文件不得上传外部平台；LLM 可配置为本地服务（Ollama）或外部 OpenAI 兼容服务

## 7. 推荐技术栈

- 前端：Vue 3 + TypeScript + Element Plus
- 后端：FastAPI
- 数据库：PostgreSQL
- 文件存储：本地目录或 MinIO
- 任务队列：Celery/RQ/Arq，V1可先用后台任务
- 音频处理：ffmpeg
- ASR：FunASR / SenseVoiceSmall
- LLM：Ollama（本地）或任意 OpenAI 兼容服务（外部），通过前端可配置、可测试
- Word导出：python-docx

## 8. 最小可用版本验收标准

上传一段会议录音后，系统能够：

1. 创建会议记录
2. 保存音频文件
3. 自动转为标准wav
4. 自动切分有效语音片段
5. 调用本地ASR生成转写文本
6. 用户可编辑转写文本
7. 用户选择模板生成会议纪要
8. 导出Word文件
